# Homebrew detector (retired)

The Homebrew Hardener is deprecated. Scan no longer runs this Detector or
reports writable Homebrew installations through it. General PATH and credential
Detectors still apply; absence of this Finding does not establish that an
installation is secure.

Existing hardened installations retain their Execution Gate and protections.
See the [deprecated hardener reference](../../hardeners/homebrew.md) for
existing-installation details and removal guidance.
